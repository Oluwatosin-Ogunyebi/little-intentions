# Submission and demo preparation

## Description

Little Intentions is a miniature delivery game that helps people practise delegating to an agent. A player briefs Orbit, reviews its plan, watches its actions, then rewinds the same world and revises the request. Feedback compares what actually happened rather than grading prompt length.

## Honest demo script (up to 90 seconds)

A 55.84-second silent, captioned desktop recording is available at `artifacts/demo/little-intentions-receipts-desktop.webm`. It shows live planner responses, two successful deliveries and their receipts. It is not headset footage or a narrated demo. The earlier `little-intentions-desktop.webm` shows Practice mode.

1. Show the source portrait and the 3D Orbit in the village. Explain the audience and that the goal is to practise clear delegation.
2. State the mission: tea to Mira. Give an incomplete request to show a useful clarification, or deliberately request cake to Rowan and approve the visible plan.
3. Show the actual delivery and event record. Rewind, revise to tea to Mira, and show both successful outcomes and their observed usage receipts.
4. Explain that execution and evaluation are deterministic and bounded. Identify Practice mode accurately if no live API is configured. Identify the Quest path as an owner-tested USB-local prototype; the recording itself is desktop footage.
